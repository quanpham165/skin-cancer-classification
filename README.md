# Skin Cancer Classification

Đề tài khóa luận kỹ sư:
Phân loại ung thư da sử dụng Deep Learning.

Dataset:
ISIC Skin Cancer Dataset
9 classes

Các mô hình đã thử nghiệm:
EfficientNetB0
EfficientNetB2
EfficientNetB3
VGG16
Swin Transformer Tiny
Swin Transformer Small
EfficientNetB0_CBAM_Vit
EfficientNetB0_CBAM_Swin-Small

Kỹ thuật sử dụng:
Transfer Learning
Focal Loss
Mixup
WeightedRandomSampler
TTA (Test Time Augmentation)
AMP Mixed Precision
Early Stopping

Metrics:
Accuracy
Macro F1-score
Recall
ROC-AUC
